# NOTE: there are deliberately NO separate "User-agent: Googlebot" /
# "Bingbot" / social-bot groups. A crawler obeys only the MOST SPECIFIC group
# that names it, so the old "User-agent: Googlebot / Allow: /" group made
# Googlebot and Bingbot ignore every Disallow above (dashboard, admin, auth).
# Those bots now follow the * group like everyone else.

# AI crawler policy — sovereignty-aligned middle path (owner policy):
#   * ALLOW AI search / answer engines on PUBLIC content. They cite and link
#     back to the page, rather than silently ingesting it.
#   * BLOCK crawlers whose purpose is model training.
#
# Each answer engine below is named so the policy is explicit. Naming one has
# a consequence: under RFC 9309 §2.2.1 a crawler obeys ONLY the group that
# names it and ignores `User-agent: *` entirely. So every group here must
# repeat the private Disallow list above in full. Until 2026-09 these groups
# carried a shorter, hand-copied list, so OAI-SearchBot, ChatGPT-User and
# PerplexityBot were allowed into tokenised /unsubscribe, /funding/confirm and
# /funding/unsubscribe links and /onboarding. src/__tests__/robots-policy.test.ts
# resolves each bot's group and fails if its access differs from `*`.
#
# /auth and /signup stay crawlable for the same reason as above: they carry a
# noindex meta tag, which a crawler can only obey if it may fetch the page.
