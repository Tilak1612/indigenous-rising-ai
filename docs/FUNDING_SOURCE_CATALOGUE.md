# Funding source catalogue (research log)

Every source read for the directory, with what was read, on which date, and
what could not be read. "Read" means the page text was fetched through
gstack's headless Chromium (WebFetch is blocked for `.gc.ca`, `.gov.*`,
`bdc.ca` and `nacca.ca` on the build machine) and the quoted facts were
written into `grants.source_evidence`.

Status key: **in catalogue (published)** existed before this work and was
re-read; **added (unpublished)** inserted by migration `20261026000002`,
awaiting owner review in `/admin`; **directory** a lender network, not a
programme; **blocked** the host refused automated reads; **not a programme**
page describes referrals only.
